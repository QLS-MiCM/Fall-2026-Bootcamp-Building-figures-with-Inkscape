# Building figures with Inkscape

## Overview

This hands-on workshop will teach participants how to use Inkscape to transform a collection of independent plots into a polished, publication-ready figure. Participants will learn best practices for working with vector graphics, importing outputs from R and Python, arranging multi-panel layouts, and adding graphical elements such as arrows, annotations, and labels. By the end of the session, attendees will be able to create clear, professional figures suitable for manuscripts, posters, and presentations.

## Requirements
* Access to [Inkscape](https://inkscape.org/) latest version (free and open source)
   
## Outline
1. Introduction to scientific figure design and Inkscape (25 min)
   * Why use Inkscape for scientific figures?
   * Vector vs. raster graphics
   * Common file formats (SVG, PDF, PNG, TIFF)
   * Best practices for publication-quality figures
   * Overview of the Inkscape interface and workflow
   
2. Importing and editing plots
   * Understanding layers, groups, and objects
   * Importing images into Inkscape
   * Basic editing of imported graphics
   * Managing fonts and text elements

3. Building a multi-panel figure
   * Alignment and distribution tools
   * Using guides, copying a color
   * Choosing fonts, colors, and line styles
   * Clipping and masking
   * Create a publication-style layout
   * Adding annotations (Drawing arrows and shapes)
   
4. Exporting and closing remarks
   * Export options
   * Additional resources

## Data

Participants are encouraged to bring PDF figures generated in R or Python, either from previous workshops or their own projects. For those who do not have their own figures, a collection of mock RNA-seq analysis outputs will be provided to practice constructing a publication-quality multi-panel figure. Mock figures were generated using RNA-seq counts from this [study](https://doi.org/10.1016/j.stem.2021.04.028).
